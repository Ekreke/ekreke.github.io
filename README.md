This is a static blog generated by [Hugo](https://gohugo.io/), hosted on GitHub Pages.

The site is built with the [Ananke](https://github.com/theNewDynamic/gohugo-theme-ananke) theme.

## Development

To run the site locally, make sure you have Hugo installed, then run:

```bash
hugo server
```

The site will be available at `http://localhost:1313/`.

## Creating a New Post

To create a new blog post, use the following command:

```bash
hugo new content posts/your-new-post-title.md
```

This will create a new Markdown file in the `content/posts` directory. Remember to set `draft: false` in the file's front matter when you are ready to publish it.

## Deployment

This repository is configured as a GitHub User Page, so any commits pushed to the `main` branch will automatically trigger a deployment.

The deployment process is as follows:

1.  **Make your changes**: Create new posts or edit existing content.
2.  **Build the site**: Run the `hugo` command. This will generate the complete static website into the `public/` directory.
    ```bash
    hugo
    ```
3.  **Commit and push**: Add all changes to git (including the `public` directory), commit them, and push to the `main` branch.
    ```bash
    git add .
    git commit -m "Your commit message"
    git push origin main
    ```

GitHub Pages will then automatically serve the files from the `public` directory.
